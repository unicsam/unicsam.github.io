Privacy Policy

Broken Navbar Fix • Effective Date: October 2026

Broken Navbar Fix is designed as a strict, offline-first assistive utility. The application requests zero internet permissions. We do not collect, store, transmit, or share any personal data, keystrokes, or screen activity. Your device preferences never leave your phone.

1. Prominent Disclosure: AccessibilityService API Usage

To provide navigation capabilities for devices with broken physical, capacitive, or display navigation keys, Broken Navbar Fix requires the Android AccessibilityService API. In strict compliance with Google Play Developer Policies, we disclose the following:

  • Specific Purpose: The AccessibilityService API is used exclusively to display the on-screen floating navigation bar overlay and trigger system navigation commands (Back, Home, and Recent Apps) when the user taps on the corresponding buttons.
  • No Data Collection: The service does NOT collect, harvest, store, or transmit any personal or sensitive user information.
  • No Keystroke Monitoring: The service does NOT monitor, record, or intercept user typing, passwords, credentials, or credit card details.
  • No Screen Inspection: The service does NOT read, inspect, or record content displayed on your screen or inside other applications.
  • User Control: Accessibility privileges are optional and can be enabled or revoked at any time by the user via Android Settings → Accessibility → Downloaded apps → Broken Navbar Fix.

2. Zero Network Access (100% Offline Architecture)

Broken Navbar Fix does not request the android.permission.INTERNET permission in its Android Manifest. It is technically and architecturally impossible for the application to transmit data, communicate with external servers, or connect to the internet.

3. Permissions Declared & Purpose

Permission Type Purpose
AccessibilityService System Accessibility Used solely to trigger system Back, Home, and Recents actions on user tap.
android.permission.VIBRATE Device Hardware Provides optional haptic feedback vibration when a navigation button is pressed.
android.permission.INTERNET Network Access NOT REQUESTED. App operates completely offline.

4. Google Play Data Safety Summary

In alignment with the Google Play Console Data Safety declaration:

  • Data Collected: No data collected.
  • Data Shared: No data shared with third parties.
  • Advertising & Trackers: Zero ads, zero third-party SDKs, zero analytics trackers.
  • Security: All configuration parameters (e.g. button sizes, colors, transparency) are saved locally within Android's private DataStore / SharedPreferences sandbox.
